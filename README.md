# 🧠 AI Flow-Builder Insights (Full-Stack MERN)

An interactive, node-based flow builder that integrates AI responses with persistent database storage. Users can visually connect logic blocks, generate AI insights, and save their history for later review.

## 🚀 Live Links
- **Frontend (Vercel):** [https://ai-mern-assignment.vercel.app/]
- **Backend (Render):** [https://ai-mern-assignment.onrender.com]

---

## 🛠️ Tech Stack

### Frontend (client folder)
- **React.js & Vite:** High-performance UI development.
- **React Flow:** For the interactive drag-and-drop node interface.
- **Axios:** For seamless API communication.
- **CSS3:** Custom styling with advanced layouts (Flexbox/Grid) and Line-Clamping.

### Backend (server folder)
- **Node.js & Express:** Scalable RESTful API architecture.
- **MongoDB & Mongoose:** Schema-based data modeling and persistent storage.
- **AI Integration:** Integration with OpenRouter for intelligent text generation.
